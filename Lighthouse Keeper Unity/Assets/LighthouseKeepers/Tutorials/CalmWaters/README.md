# Calm Waters tutorial scene

Open `Assets/Scenes/CalmWaters.unity` and press Play. Calm Waters is also the first enabled scene in Build Settings.

- Select **Begin Calm Waters** to start the warm-up.
- Hold **Space** to widen the lighthouse beam; release it to let the beam settle back to a gentle lamp glow.
- After a little practice, select **Finish Calm Waters**.

This warm-up has no boats, score, or failure state. Its scene art is generated at runtime on the 240 × 135 pixel grid and uses the selected theme from `LighthousePaletteCatalog`.
